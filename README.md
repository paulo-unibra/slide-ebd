# Memórias — slideshow de fotografias

Abra `index.html` no navegador. Não precisa instalar dependências nem iniciar servidor. Mantenha a pasta `images` junto do HTML.

- 8 fotos originais, sem cortes; anexos duplicados removidos por SHA-256.
- Transições aleatórias sem repetir o último efeito, ou efeito fixo.
- Tempo ajustável de 1 a 120 segundos, reprodução/pausa e loop opcional.
- Organização manual da sequência, embaralhar e restaurar a ordem original.
- Sequência salva no navegador quando o armazenamento local está disponível.
- Tela cheia; setas para navegar, espaço para pausar e F para tela cheia.
- Respeita a preferência de redução de movimento do sistema.

## Enviar ao GitHub
Crie um repositório e envie `index.html`, este README e a pasta `images` na raiz. As fotos permanecem locais e não dependem de serviços externos.
